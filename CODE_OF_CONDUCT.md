# Code of Conduct

Be respectful, constructive, and welcoming to everyone. Not okay: harassment, personal attacks, discriminatory or sexualized language, or trolling.

This applies in all project spaces (issues, PRs, discussions). Report unacceptable behavior via a [private security advisory](https://github.com/MalyStern/quickfile-actions/security/advisories/new). Maintainers may remove violating contributions and ban repeat offenders.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.
